02 / VERIFICATION STACK

A screenshot is not the rule that marks a medical case paid.

LAYER / 01

Server-created order

AVC's private backend creates the Razorpay Order using the fixed ₹1,770 AVC service amount rather than accepting an arbitrary amount from the browser.

LAYER / 02

Razorpay Checkout

Payment authorization and payment-method credentials are handled inside Razorpay Checkout, not through a custom AVC card or UPI credential form.

LAYER / 03

Signature verification

The private backend verifies the Razorpay order/payment references and cryptographic signature before accepting the payment response.

LAYER / 04

Amount + currency check

The payment is checked for the expected INR currency and exact AVC amount rather than trusting client-side display values.

LAYER / 05

Captured status

The backend checks the payment state before the related medical case is treated as paid.

LAYER / 06

Case creation

A paid AVC medical case is created only after the server-side payment verification path succeeds.

03 / DATA BOUNDARY

Medical identity data and payment credentials belong to different systems.

AVC private medical API

  • Candidate name and contact information
  • Passport and booking identity details
  • Destination, city, visa type and trade
  • AVC medical case status and Wafid processing metadata

Razorpay Checkout

  • Payment method and authorization
  • Razorpay order/payment references
  • AVC service description and fixed payment amount
  • No need to place passport number in Razorpay order receipt/notes for this flow
Credential rule

Do not share card PIN, CVV, UPI PIN, banking password or payment OTP with AVC staff, unknown contacts or a verification email. Payment credentials belong only in the authorized payment interface.

04 / CONFIRMATION PROTOCOL

After payment, keep two references and use them for reconciliation.

01 / PAY

Complete Checkout

Use the medical-booking payment route and complete payment inside Razorpay Checkout.

02 / VERIFY

Server check

The backend verifies the Razorpay response, amount and payment state.

03 / RECORD

Keep references

Retain the Razorpay Payment ID and the AVC medical reference created for the case.

04 / TRACK

Check case status

Use the medical-case tracking route or official AVC support instead of paying again when a confirmed payment needs reconciliation.
