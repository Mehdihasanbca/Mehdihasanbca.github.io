Tax treatment note

Exact third-party reimbursement is not automatically GST-free. Pure-agent treatment is used only when the actual transaction satisfies the applicable Rule 33 conditions, including candidate authorization, separate disclosure and recovery of the exact third-party amount without markup.

02 / REFUND BY STAGE

Refundability depends on what has already happened.

STAGE / 01

Before service starts

If AVC has not started material work and no third-party amount has been incurred, a cancellation request can be reviewed for the unused service amount, subject to applicable law.

STAGE / 02

After AVC work starts

If material booking or coordination work has already been performed, the refundable service portion depends on the actual work completed and applicable law.

STAGE / 03

After Wafid cost is incurred

An actual Wafid/third-party amount already paid for the candidate's approved case is subject to that third party's own cancellation/refund rules.

03 / PAYMENT EXCEPTIONS

Use the payment reference to resolve exceptions instead of creating another payment.

EXCEPTION / 01

Failed / pending

A failed Razorpay attempt does not create a paid AVC medical case. The medical flow does not treat payment failure alone as a completed paid case.

EXCEPTION / 02

Duplicate payment

The private medical API prevents duplicate case creation for the same verified Razorpay Payment ID. A true duplicate charge can be reconciled from Razorpay references and reviewed for refund.

EXCEPTION / 03

Payment succeeded, case missing

Do not pay again. Contact AVC with the Razorpay Payment ID so the transaction can be reconciled against the server-side order and candidate details.

EXCEPTION / 04

Refund initiated

After an approved refund is initiated, final credit timing depends on Razorpay, the issuing bank and the payment method.

EXCEPTION / 05

Third-party cancellation

Any already-incurred Wafid/third-party amount follows the applicable third-party cancellation/refund rules rather than being treated as unused AVC service revenue.

EXCEPTION / 06

Reference missing

Use the official AVC support route and provide available payment/date/contact context without sharing OTPs, passwords or banking credentials.
